Rules

  1. Save all SQL in one file named <student_number>_exam.sql. Run it top to bottom.
  2. Use the table and column names exactly as given in the dictionary below.
  3. Where a question asks for an alias, use the exact name given.
  4. Put a comment above each answer, for example -- A2.
  5. Choose one dashboard tool for Section F: Power BI or Looker. State your choice at the top of your SQL file, for example -- Section F tool: Looker.
  6. Work independently. Do not discuss answers with other students.

Loading the data into SQL Server

1
Create the database SunVolt and switch to it (Section A1).
2
Create the customers table with the 16 columns in the dictionary, then the distance_bands table with its five rows (Sections A2 and A3).
3
Import the Excel sheet into customers using the SSMS Import Data wizard. Map Distance from Nearest Installer to distance_band and leave out Installer Distance Order (Section A4).
4
Check the import: customers should hold 1,026 rows.
